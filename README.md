# Eisberg WordPress Theme

This is a classic WordPress theme converted from the Eisberg HTML page prototypes.

## Install

1. Copy the `Eisberg` folder into `wp-content/themes/`.
2. Activate **Eisberg** under **Appearance > Themes**.
3. Create pages with these slugs: `produkt`, `preise`, `faq`, and `fuer-schulleitungen`.
4. Set the homepage under **Settings > Reading**. The homepage uses `front-page.php`.
5. Set the logo under **Appearance > Customize > Site Identity**.
6. Optionally create a menu under **Appearance > Menus** and assign it to **Hauptnavigation**.

The original prototypes reference image and video assets that were not included in the workspace. Replace the media placeholders by adding WordPress media or editing the templates.
